# Minimal Skill Example

Use this skill as a compact reference for the smallest useful Codex skill.

## Workflow

1. Confirm the task benefits from a reusable instruction.
2. Keep the skill body concise.
3. Put required trigger details in the `description` field.
4. Add scripts or references only when they remove repeated work.

## Output

Return a short explanation of what the skill does and the smallest next action
the user can take.
