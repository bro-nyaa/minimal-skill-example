# Minimal Skill Example

Create the smallest useful implementation brief for the user's project idea.

## Workflow

1. State one concrete goal in a single sentence.
2. Give exactly three implementation steps.
3. Finish with one observable verification check.
4. Avoid optional features, dependencies, and abstractions unless requested.

## Output

Use this format:

```text
Goal: <one sentence>

Steps:
1. <first step>
2. <second step>
3. <third step>

Verification: <one command or observable result>
```
